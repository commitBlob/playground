# Skills and Prompts

## Help-me-prepare.md
This skill provides a comprehensive facilitator preparation guide for hackathon challenges, designed for Forward Deployed Engineers acting as technical anchors. It covers challenge deep-dives, domain knowledge requirements, technology recommendations, common pitfalls, time-boxed milestone plans, AI coding tool strategies, and unblocking playbooks to help teams build successful prototypes within one day.

## stakeholder-power-interest-matrix.skill
This skill assists in stakeholder analysis by creating a power-interest matrix, a strategic tool that categorizes stakeholders based on their level of power (influence over the project) and interest (level of concern or involvement). It helps identify key players, prioritize engagement efforts, and develop communication strategies to manage stakeholder relationships effectively throughout a project lifecycle.

## write-adr.skill
This skill helps teams draft an Architecture Decision Record (ADR) by capturing the context, decision rationale, alternatives considered, and consequences for significant technical choices. It supports consistent documentation, clearer communication across engineering stakeholders, and better long-term traceability of architecture decisions.

# Commands
## create-worktree.md
This Claude Code command helps automate creating a new Git worktree, enabling faster branch workflows and parallel context switches across repositories.

## merge-worktree.md
This Claude Code command helps merge changes from a worktree back into the main repository branch, simplifying cleanup and integration for parallel Git workflows.
